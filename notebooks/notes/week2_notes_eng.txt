Arithmetic modulo q :
Calculation by module.
Can also be in negative numbers: x mod q = x + k ⋅ q , for example:
-1 mod 7: 
-1 + 7 = 6 → -1 ≡ 6 (mod 7)
-2 mod 7: 
-2 + 7 = 5 → -2 ≡ 5 (mod 7)
-7 mod 7: 
-7 + 7 = 0 → -7 ≡ 0 (mod 7)
-8 mod 7: 
-8 + 7 = -1 (still negative!) -1 + 7 = 6 → -8 ≡ 6 ( mod 7) 
(that is, here k = 2: -8 + 2 7 = 6)

Centered modular representation :
Takes the usual remainder modulo q (a number in {0, ..., q - 1}) and then shifts it to a symmetric range around zero, for example:
Example: x = -8, q = 7
	The usual remainder is -8 mod 7 = 6
	6 > 7//2 (=3) → yes, so we subtract q: 6 - 7 = -1
Result: -8 ≡ -1 ( mod 7) in centralized form.

Vectors and matrices modulo q:
The same as ordinary vectors and matrices of linear algebra, only each element after any operation (addition, multiplication) is reduced modulo q .

Polynomial addition and multiplication:
A polynomial is expression type :
a(x)=a_0+a_1 x+a_2 x^2+⋯
a(x) = a0 + a1x + a2x^2 + …
where a_0,a_1,a_2,…a 0, a 1, a 2,… are coefficients (numbers). A polynomial can be represented simply as a list of coefficients:
a(x)=4+5x ↔ [4ⓜ,5]
a(x) = 4 + 5x ↔ [4, 5]

The quotient ring Rq = Zq[x]/(xn + 1):
The key structure for ML is KEM and Module is LWE .
Zq — numbers modulo q (the coefficients of the polynomials "live" here)
Z_q [x]Zq [ x ] — all polynomials with coefficients modulo q , of any degree
/(x^n+1)/( xn +1) — "divide" by the polynomial x^n+1, that is, reduce it to the modulus of this polynomial. n determines the number of coefficients in the polynomials.
x ^ n + 1 = 0 => x ^ n = -1 Just like for 7 = 0 mod 7.
For mod 7: …, 5, 6, 0 (would be 7), 1, 2, …
For mod ( x ^2 + 1) : … , x ^0 – 1, x ^1 = x , x ^2 = -1 (it would be = x ^2), x ^3 = - x , x ^4 = 1, …
The range of powers for mod ( x ^ n +1) is [0, 1, …, n – 1]
The sign changes on overflow (if the degree >= n ), with the regularity (for n = 2) every n = 2 degrees.
Example:
Let's take:
a ( x ) = 3 + 4 x , b ( x ) = 2 + 3 x
Step 1. Regular multiplication (open the brackets)
a(x)b(x) = 3 ⋅ 2 + 3 ⋅ 3x + 4x ⋅ 2 + 4x ⋅ 3x
=6+9x+8x+12x^2 = 6 + 9x + 8x + 12x^2
=6+17x+12x^2 = 6 + 17x + 12x^2
Step 2. Apply the ring rule ( x^2=-1) – this is where the sign changes!
The degree x^2has appeared - we replace it with-1:
12x^2=12⋅(-1)=-12
Means:
6+17x+(-12)=(6-12)+17x=-6+17x
Step 3. We reduce the coefficients modulo q = 7

-6 mod 7 = 1 (−6+7=1)
17"  mod" 7=3 (17=2⋅7+3)
Result
a(x)⋅b(x)≡1+3x  (modⓜ, 7" " x^2+1)
Why exactly x ^ n + 1? Because x ^ n would produce a lot of zeros, which is bad, and x ^ n – 1 could be factored, which is also bad.

W hy multiplication by x^n = −1 produces negacyclic wrap-around:
Because the degree is looped in the ring [0, 1, …, n – 1] and the sign can change.

The basic LWE equation b = As + e (mod q):
A is a matrix (random numbers) - public
s - secret vector – secret
e - small noise vector (error) - secret
b - the result (what is published) - public
q - module - public
We take a known matrix A , multiply it by a secret vector s , then add some random noise e , and reduce all this modulo q .
The result b becomes public - anyone can see it, including the attacker.
It's difficult to crack due to the addition of the error e and the large number of possible secrets. NP is a hard problem. We can't ignore the error and round because we're working modulo, which completely changes the result when dividing or inverting the matrix modulo q .
Grover gives a quadratic speedup of the search ( √Ninstead of N), but even this does not help with the astronomical N of the real ML - KEM .

Why the small error vector e makes secret recovery nontrivial:
Because without an error, it is very easy to find a secret (one unknown), but if an unknown error appears, it forces you to try to find the secret, and the number of possible secrets in real ML - KEM is simply cosmic, the number of search algorithms grows like 2^O(n) .
